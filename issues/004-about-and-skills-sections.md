# Build About and Skills Sections

## What to build

Implement the About Section and Skills Section as the second and third blocks of the single-page layout.

**About Section**: Renders the summary paragraph from Portfolio Data. Clean typography, adequate whitespace, with the section heading styled using the Accent Gradient.

**Skills Section**: Renders skills grouped by category (Programming & Frameworks, DS & ML, Visualization & Reporting, Databases & Cloud, Tools & Platforms). Each category has a heading and its skills displayed as tags/chips. The section heading uses the Accent Gradient.

All content is read from Portfolio Data.

## Acceptance criteria

- [ ] About Section renders the summary paragraph from Portfolio Data
- [ ] Skills Section renders all 5 skill categories with their respective skills
- [ ] Skills are displayed as compact tags/chips within each category
- [ ] Section headings use the Accent Gradient
- [ ] Both Sections have `id` attributes matching the navbar anchor links
- [ ] Layout is responsive — stacks cleanly on mobile
- [ ] All content is driven from Portfolio Data — no hardcoded strings
- [ ] `pnpm build` succeeds
